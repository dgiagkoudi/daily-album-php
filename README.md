# Daily Album (PHP)
Μικρή εφαρμογή PHP που εμφανίζει τον δίσκο της ημέρας από ένα JSON αρχείο και επιτρέπει στους χρήστες να προτείνουν νέα albums.

## Περιγραφή
Η εφαρμογή παρέχει:
- Ανάγνωση δεδομένων albums από αρχείο JSON.
- Τυχαία αλλά σταθερή επιλογή δίσκου βάσει ημερομηνίας.
- Προβολή εξωφύλλου και στοιχείων δίσκου.
- Αποθήκευση των υποβολών από τη φόρμα προτάσεων στο αρχείο suggestions.json.

## Τεχνολογίες που χρησιμοποιήθηκαν
- PHP
- HTML5
- CSS3
- JSON

## Τοπική εκτέλεση
1. Μεταφέρετε τον φάκελο στο htdocs του XAMPP.
2. Εκκινήστε τον Apache server.
3. Ανοίξτε: http://localhost/daily-album/
